# Contributing

Read `RULES.md` and `AGENTS.md` before making a change. Keep routes thin, place feature work under `src/features/`, and avoid app-specific branding in this template.

Run `npm ci`, make a focused change, then run `npm run check`. Open a PR against `main` with the Charter sections in `.github/PULL_REQUEST_TEMPLATE.md`. Include the CI run and any device testing in the Proof section.
